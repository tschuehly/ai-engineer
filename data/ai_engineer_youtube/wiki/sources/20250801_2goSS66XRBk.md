## Summary

Jesse Han presents Morph's Infinibranch and Liquid Metal as cloud infrastructure for agents that need fast, reversible, branchable software environments. The durable engineering idea is that VM or container snapshots can become a substrate for parallel test-time search, verifier-checked agent branches, and reasoning models trained to use external software and formal verification loops.

## Notes

- Infinibranch is described as virtualization, storage, and networking technology for thinking machines that need to interact with complex software environments with near-zero latency. 04:11-04:30
- Full cloud VMs can be snapshotted, branched, and replicated in a fraction of a second, making browser and computer-use mistakes reversible and enabling agents to explore multiple paths. 04:48-05:52
- Morph Liquid Metal adds container runtime support, millisecond branching, autoscale-to-zero and autoscale-to-infinity, and planned GPU support. 06:11-06:42
- A cloud-for-agents should declaratively specify workspaces, pass workspaces between humans and agents, and scale test-time search against verifiers. 07:23-07:50
- Snapshot workflows behave like Docker layer caching or "git for compute", where side effects can be layered and idempotent durable agent workflows can branch from a declared snapshot. 08:25-09:08
- In the server demo, parallel agents try different ways of starting a server on port 8000; a failed branch can be ignored while the successful solution is passed into the workflow. 09:08-09:28
- Reasoning-time branching means not only calling tools, but replicating and branching environments so agents can decompose problems and explore them in a verified way. 12:10-12:28
- The chess demo uses a restricted chess engine as a verifier; branchable subagents explore more of the solution space and recombine checked results into a move. 11:35-13:38
- The talk frames future verified reasoning as using external software and formal verification software to produce algorithmically checkable outputs. 15:20-16:38
