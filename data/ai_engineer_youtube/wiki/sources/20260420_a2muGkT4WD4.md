## Summary

Adrien Grondin gives a practical path for Apple-device local inference: use MLX and MLX Swift LM in native iOS, iPadOS, or macOS apps, pull compatible quantized weights from the Hugging Face MLX community by model ID, and choose quantization and model catalogs around real phone throughput, download size, and quality constraints.

## Notes

- MLX is described as an Apple framework optimized for Apple Silicon, with Locally AI using it to run on-device models on iPhone and also supporting iPadOS and macOS. (01:22-01:47)
- The practical developer path is to add MLX Swift LM to an iOS, iPadOS, or macOS app, choose a model from the Hugging Face MLX community, and pass the model ID to the framework so it can download the model. (02:04-02:36, 04:18-04:39)
- The MLX ecosystem is framed as broader than text: the talk references MLX VLM, MLX audio, and MLX video for visual, audio, image-generation, and video-generation workloads. (02:39-03:14)
- The MLX community on Hugging Face is presented as an active source of full and quantized weights, with many variants such as BF16, MXFP4, 4-bit, 5-bit, 6-bit, and 8-bit. (03:20-04:16)
- For iPhone deployment, the talk recommends using quantized versions because full-size weights are too large; below 4-bit quality degradation becomes significant, while 4-bit to 8-bit is the practical range. (04:41-05:18)
- A live offline demo showed Gemma 4 8-bit quantized to 4-bit on a recent iPhone reaching roughly 40 tokens per second; the speaker says even roughly 20 tokens per second on older iPhones can be useful for many app workflows. (05:39-07:04)
- The main user-facing barrier is still local model download size, commonly around 1-3 GB depending on the model. (07:12-07:30)
- MLX Swift LM supports tool calling, but structured generation is not yet built in directly; packages on top of MLX Swift LM are emerging for that gap. (09:02-09:38)
- Locally AI curates model choices rather than exposing every open model because not all compatible-looking models work well on iPhone. (10:12-10:25)
