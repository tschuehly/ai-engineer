## Summary

Jeremiah Lowin argues that MCP servers should be designed as agent-facing products rather than generated REST wrappers. The useful interface is a curated set of outcome-oriented tools that respects agent discovery, iteration, and context limits; generated endpoint mirrors can help bootstrap experiments, but shipping broad REST-shaped MCP surfaces to production wastes context, confuses tool selection, and pushes deterministic orchestration into stochastic model calls.

## Notes

- MCP servers are agent interfaces and should be designed around agent strengths and weaknesses, rather than assuming an agent can use a raw API just because a human developer can. 04:24-05:56
- Discovery is expensive for agents because a session handshakes with the server and enumerates tool names and descriptions; iteration is also expensive because additional calls can carry the accumulated conversation history. 06:12-07:37
- Effective MCP design should prefer outcomes over operations and should not include tools unless they are expected to produce useful workflow results. 14:47-15:18
- Atomic REST operations are useful API design but poor MCP defaults; known orchestration should be handled by the server instead of forcing the LLM to act as glue. 15:25-16:21
- "One tool equals one agent story" means a tool should map to a recognizable objective for a programmatic autonomous agent with limited context. 16:21-16:42
- A large endpoint mirror can exhaust context at handshake; the talk gives an 800-endpoint example and warns that token budget matters even when each tool has a very small description and schema. 28:25-29:24
- More than roughly 50 tools visible to one agent is treated as a performance smell; the speaker suggests splitting tools by role or namespace and investing in evaluation when a larger surface is unavoidable. 35:32-37:14
- REST-to-MCP generation can bootstrap early testing, but should be curated after the agent can use the tool; shipping the generated REST mirror to production is presented as a mistake. 38:20-39:59
