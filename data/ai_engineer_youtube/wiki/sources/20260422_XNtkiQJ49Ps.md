## Summary

Jacob Lauritzen argues that vertical agents need collaboration surfaces beyond linear chat because complex work shifts the bottleneck to planning, review, trust, and control. The talk frames agent reliability around task verifiability, decomposition, guardrails, node-level skills, decision logs, and persistent high-bandwidth artifacts such as documents and tabular reviews where humans can inject judgment at the right point in a work tree.

## Extracted Concepts

- [Make agent work more trustworthy by making it verifiable](../concepts/make-agent-work-more-trustworthy-by-making-it-verifiable.md) - this source explains why agents perform better on tasks with cheap verification and how proxy checks, decomposition, and guardrails raise trust.
- [Use decision logs to keep uncertain agents moving](../concepts/use-decision-logs-to-keep-uncertain-agents-moving.md) - this source describes letting agents make reversible assumptions while recording uncertainty for later human review.
- [Collaborate with complex agents through high-bandwidth artifacts](../concepts/collaborate-with-complex-agents-through-high-bandwidth-artifacts.md) - this source argues that documents, tables, and other persistent artifacts are better control surfaces than one-dimensional chat for large work trees.
- [Encode domain judgment in node-level agent skills](../concepts/encode-domain-judgment-in-node-level-agent-skills.md) - this source describes skills as a way to put human judgment and contingencies directly into recurring nodes of agent work.

## Notes

- Long-running agents that research, launch subagents, write files, and compact context can make targeted user corrections hard to trust because a later run may change more than the requested clause. 00:45-01:38
- As execution gets cheaper, the bottleneck shifts toward planning work, non-functional requirements, specs, and reviewing generated output. 02:31-03:09
- The talk applies the verifier's rule to agents: solvable work that is easy to verify can be looped on until it improves, while legal strategy or product taste remains much harder because objective verification is weak. 03:20-05:13
- Trust can improve by making work more verifiable through browser access, TDD, golden examples, proxy checks, decomposition, and guardrails that limit files, directories, websites, or actions. 05:51-07:49
- Upfront planning improves control but cannot cover contingencies discovered only after work starts; skills can encode domain-specific handling at the relevant node of the work tree. 08:39-10:28
- Elicitation should avoid blocking the whole run: when uncertain, an agent can make a decision, record it in a decision log, and let the human reverse it later. 10:35-11:13
- Chat is useful as flexible input, but complex agents need persistent high-bandwidth artifacts such as documents, comments, tagged agents, and tabular review surfaces for scalable collaboration. 11:15-13:20
