## Summary

Ankur Goyal argues that eval work is moving from passive dashboards and manual prompt edits toward agent-assisted optimization loops. Braintrust's Loop is described as an eval-native agent that can propose improvements to prompts, datasets, and scorers while keeping data, prompts, and suggested changes visible in the product UI.

## Notes

- Braintrust's customer usage is presented as evidence that mature AI product teams already run evals heavily: the average signing organization runs almost 13 evals per day, some customers run more than 3,000 per day, and advanced users spend more than two hours per day working through evals, 00:55-01:19.
- Goyal argues that even a good eval dashboard can remain passive: teams still leave the dashboard to decide which code or prompt changes might improve results, 01:40-01:57.
- Loop is described as an agent inside Braintrust that became possible because Braintrust had been evaluating frontier models on their ability to improve prompts, datasets, and scorers; Goyal says Claude 4 was a breakthrough in that capability, 01:59-02:39.
- Loop can optimize prompts through complex agents, and it also helps improve datasets and scorers because prompt, dataset, and scorer quality combine to produce strong evals, 02:39-02:56.
- The UI is designed to preserve human inspection: when Loop suggests data edits, scorer ideas, or prompt edits, users can view those changes side by side instead of losing contact with the underlying artifacts, 03:31-03:56.
