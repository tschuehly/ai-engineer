## Summary

Ido Salomon presents AgentCraft as a game-inspired orchestration interface for managing many coding agents without making the human operator the bottleneck. The talk emphasizes spatial visibility over agent activity, filesystem-level lineage and collision awareness, agent-suggested task queues, containerized autonomous decomposition, review bundles with visual evidence, and collaborative workspaces where multiple humans and agents can see and hand off work.

## Notes

- Spinning up many agents is not the hard part; the human becomes the bottleneck when asked to orchestrate many parallel, unreliable workers directly. 00:32-01:20
- AgentCraft treats coding-agent sessions from tools such as Cursor, Claude Code, Codex, and OpenClaw as detectable and spawnable units inside one orchestration surface. 02:10-02:32
- The interface maps directories and files into rooms so the operator can see which agent is working on which file, inspect the changelist, and retain lineage over which agent changed what and when. 03:36-04:31
- Heat maps can make likely collisions visible and potentially prevent them before parallel agents overwrite or duplicate each other's work. 04:33-04:44
- Fast cycling between agents is useful for plan approvals and questions, but still leaves the human babysitting every work stream. 04:47-05:57
- A further step is to give agents a broad feature idea, run them in a container, let them decompose and plan the work, and move human effort mostly to planning approval or review. 06:00-06:42
- Agent-suggested quests can turn refactoring, testing, and other maintenance ideas into one-click work items, while cron-driven channels can scan external sources for implementation ideas that later produce PRs to review. 05:28-05:46, 06:45-07:05
- Review bundles summarize what changed, why it changed, which tasks were attempted, and visual evidence such as screenshots or videos so the human can review parallel PRs faster. 07:03-07:25
- Shared workspaces let a teammate's agent and the speaker's agents see each other, expose current work, and hand off from one person's agents to another's. 07:57-09:24
