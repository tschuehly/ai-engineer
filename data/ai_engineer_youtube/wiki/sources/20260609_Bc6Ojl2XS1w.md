## Summary

Thor Schaeff (developer experience, Gemini API and Google AI Studio) walks the Gemini audio stack as one layered system built on Gemini 3 audio understanding. A single Gemini 3 Flash Preview call extracts a rich structured profile from a recording — speaker labels by name, accurate timestamps, per-segment language detection with English translation, emotion tags, and a summary — populated into a UI via a response schema rather than chained through separate ASR, diarization, language-ID, and emotion models. The same audio understanding powers speech generation: instead of picking from a large filterable voice catalogue, you take a small set (~30) of base voices and direct them with a natural-language "director's note" (audio profile, scene, performance guidance, sample context, transcript) so the model can synthesize accents and personas it knows the sound of. Gemini 3.1 Flash Live is a native sound-to-sound real-time multimodal model that ingests text/audio/video over a WebSocket and returns audio plus a text transcript, with thinking baked into the model rather than cascaded through a separate text LLM. The talk closes by orchestrating generative media from the live voice agent: a "Life Jukebox" gives Gemini Live a tool to call Lyria 3 (clip and Pro variants, now with lyrics) to generate a full song on request.

## Notes

- Audio understanding is positioned as the foundation under everything: the frontier Gemini 3 models do the base audio research, and dedicated audio (speech-gen, real-time) models are built on top, 07:32-08:08.
- "EchoScript" demo (built in Google AI Studio, in the gallery): one API call to Gemini 3 Flash Preview prompted to identify distinct speakers, label them by name when there is context, give accurate timestamps, detect language, translate to English when not English, classify emotion from {happy, sad, angry, neutral}, and produce a brief summary at the start; output is structured via a response schema and rendered into the UI, 04:16-07:24.
- Rich transcription handles overlapping speakers and seamless code-switching between languages, distinct from pure transcription, 04:00-04:12, 05:17-05:27.
- Speech generation: typical TTS providers ship a huge library filtered by gender/accent/language; Gemini ships ~30 base voices that you direct to act a certain way, modifying the base voice because the model understands what scenarios sound like, 08:10-09:00, 11:41-11:55.
- "Voice Library" app (AI Studio gallery): prompt structure is audio profile + scene + director's note (performance guidance, like directing a human) + sample context + transcript; e.g. "high pitch Irish male" had Gemini 3 Flash construct the system prompt — character "Finian," scene a cozy pub on the coast of County Clare, deliver with a strong authentic Irish accent — transforming a standard American base voice; another turned the "Zephyr" voice into Singaporean Singlish, 09:03-11:33.
- Gemini 3.1 Flash Live: full-duplex sound-to-sound real-time multimodal; ingests text/audio/video over a WebSocket, returns real-time audio plus a text transcript; thinking/reasoning/intelligence is baked directly into the model rather than cascaded through text→LLM→speech; try at `ai.studio/live` with no credit card, 02:42-02:57, 12:08-13:27.
- Live demo: camera vision ("can you see me?", outfit comment) plus a German poem; the model carried the Irish accent into German, so system instructions must constrain accent per language; screen/video frame ingest is capped at 1 frame per second currently, 13:28-15:08.
- Benchmarks in the audio space are explicitly called untrustworthy, 12:31-12:34.
- Dev resources: docs link Python server-to-server and JavaScript client-to-server Live examples; Google publishes coding-agent "Gemini skills" for all Gemini APIs including the Live API, because real-time audio is harder to wire up and installing the skills steers coding agents toward correct usage, 15:12-15:55.
- Lyria 3 music generation now produces songs with lyrics; two models — Lyria 3 clip (clip generation) and Lyria 3 Pro (full-length song generation), 16:02-16:38.
- "Life Jukebox" app: gives the real-time Gemini Live model a tool to generate a song via Lyria; the DJ persona conversationally elicits vibe and buzzwords, then calls the tool to produce a "German techno Schlager about the UK startup scene," 16:42-18:08.
- Roadmap mentions: Gemma 4 bakes in audio understanding for on-device/edge use, 01:50-02:11; gen-media video models include audio generation, 02:14-02:39.
