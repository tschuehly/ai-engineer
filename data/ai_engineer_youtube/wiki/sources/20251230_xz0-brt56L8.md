## Summary

Ivan Leo frames Manus as a general action engine exposed through web, Slack, browser, Microsoft 365, and API surfaces, then demonstrates how the Manus API can dispatch asynchronous agent tasks, preserve context across follow-up messages, call browser/sandbox/file/connectors, and turn private sources such as Notion policies plus uploaded receipts into research and workflow outputs.

## Notes

- Manus is described as an action engine that executes tasks, automates workflows, and extends human reach across web, Slack, API, browser operator, Microsoft 365, and mail surfaces (00:58-02:58).
- The API exposes the same capabilities as Manus chat, including sandboxed work, browser operation, Notion/custom MCP-style context, code, files, and internally used Slack/Zapier/n8n integrations (12:34-13:32).
- Creating an API task returns a task ID, title, and task URL; applications use the task ID to retrieve state, send follow-up feedback, and keep complex workflow context inside the same chat/task (17:15-22:20).
- Polling is presented as the easiest prototyping path, while webhooks are used when the final answer needs to be delivered back to an integration such as Slack (21:57-22:39, 61:53-62:11).
- The Slack bot stores task ID, task URL, Slack channel, thread timestamp, user, and status in a key-value map, then maps a Slack thread back to the same Manus task for follow-up messages (56:30-57:33, 59:34-61:46).
- The connector demo uses Notion company policies and uploaded receipt files; Manus uses OCR plus connector context to answer whether expenses fit the policy and update a Notion page (69:08-71:24).
- For API adoption, the recommended workflow is to try the work in the web app first, see whether it succeeds repeatedly, then test API requests and required context until the request shape is consistent (73:22-73:56).
- Browser use through a user's own browser requires explicit permission design because the product should not arbitrarily open local tabs; this was described as roadmap work rather than current API behavior (78:43-79:21).
