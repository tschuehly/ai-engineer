## Summary

No local transcript is available for this video, so it was recorded for provenance only and no concept or topic pages were derived from it. Per the description, Rémi Louf (.txt) took two weeks away from running a 15-person company to run personal agents and let each week-one failure dictate a runtime primitive: a voice note that vanished became an append-only log where nothing is discarded and every event is causally linked to the event that triggered it; a daily brief that posted to Slack twice became a real queue that counts attempts; and a market brief that degraded after unversioned, unrecalled prompt edits became a content-addressed prompt store. In that store every prompt component is hashed and stored separately — system message, each skill description, each tool definition, the user question — so a prompt is a list of hashes rather than a rendered string, which makes a diff between two runs show exactly which component changed and lets a run be replayed against a different model by rebuilding the request from the graph. The stated motivation is that a live chat session does not show what the model actually saw once compaction and unshared reasoning are in play. The rest is deliberately small: agents are Markdown files dropped in a folder so non-programmers can add one, they subscribe to events rather than living in a graph with edges to maintain, and typed tool calls plus typed events are the two boundaries — introduced because roughly 20% of his events were coming back malformed and getting rejected. He describes the result as a kernel rather than a framework, and reports twenty agents running on it.
