## Summary

Jack Morris argues that long-tail, private, or post-cutoff knowledge cannot be solved by prompt wording alone, and that full-context prompting and RAG each have durable limits. The source frames context as expensive working memory, embeddings as useful but leaky and weakly adaptive retrieval state, and weight updates as a potential memory layer when teams can pay training-time cost, curate synthetic data, and avoid naive whole-model memorization.

## Notes

- Long-tail tasks such as private partnership terms, company monorepos, personal writing style, medical histories, or recent facts are hard when the needed knowledge is outside training data, underrepresented, or unavailable to the model. (00:46-02:21)
- The talk presents three knowledge-injection paths: full context, RAG, and training knowledge into weights. (02:35-03:16)
- Full-context prompting can work for small bounded data such as a medical record, but large prompts increase dollar cost and latency; the cited example drops from roughly 10,000 tokens per second with 1,000 tokens of context to roughly 130 tokens per second with 128k tokens of context. (03:30-05:08)
- The self-attention bottleneck means every token attends to every other token, creating a quadratic memory and compute pressure as context grows. (05:16-05:54)
- Large context windows can avoid hard failure without preserving reasoning quality; the speaker cites Chroma's "Context Rot" report and says performance worsens as irrelevant or additional context grows. (06:18-07:51)
- RAG and vector databases are described as the production memory pattern for internal question-answering and ChatGPT-style memory, but embeddings are not a future-proof memory substrate. (10:18-11:54)
- Embeddings can leak source-like text: the speaker says a motivated attacker can train a reconstruction system and reports recovering most text at some lengths from vector database embeddings. (13:12-14:39)
- Generic embeddings can be too global for a specialized corpus; a Visa/Mastercard example shows credit-card documents clustering in a small region until contextual embeddings adjust vectors using surrounding documents. (14:43-17:12)
- Better-than-RAG approaches shift cost: deep research spends at inference time, while weight-updated specialized models spend more up front on data and training for cheaper future inference. (21:09-22:14)
- Naively fine-tuning on a small document set can memorize and degrade general use; the source says useful weight updates need better training data and a better way to update the model than overwriting all parameters. (26:01-29:21)
- A cited pattern is to expand a small source dataset into a larger, diverse synthetic dataset that preserves the original facts, then train on that so the model can answer variant questions rather than only regurgitate exact text. (30:50-32:26)
