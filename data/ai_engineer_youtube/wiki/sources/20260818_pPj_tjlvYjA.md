## Summary

Ekaterina Deyneka, founder and CEO of Reelful, describes an agentic video editor for consumers: the user drops in raw photos and videos plus a line of direction, and an agent understands the media, picks the usable moments, assembles them, and generates captions, music, voiceover, and b-roll around them. Her framing for an AI-engineering audience is that this is structurally the same system as an agentic app builder — prompt UI, a sandbox on a remote machine, an agent with tools and skills, an artifact, a render — with the codebase swapped for a video composition and the app preview swapped for a rendered video. Two differences carry the talk's content. First, Reelful edits real footage rather than generating it, which she argues is the harder problem: a blank canvas lets the agent do anything, while real material forces it to judge which take is best and what to drop, and to reach a polished result from footage that is often messy or incomplete. Second, the composition layer is Remotion — video expressed as React code — chosen precisely because agents write code well, with a verification layer that catches compositions that will not render and sends the agent back around. Skills carry the domain taste: cut rules, font pairings, when b-roll helps. The delivery half of the talk is about hiding all of it: mobile-first, directional templates so users need no prompt at all, and a conventional manual editor for post-generation tweaks.

## Notes

- The motivating gap is behavioral, not technical: nearly every hand went up for "who took a photo or video during this conference," almost none for "who actually posted any video content from it online." Deyneka counts herself in that gap — she recorded at conferences, events, trips, and meetups and never posted, "because video editing is hard… it's tedious and it's largely still manual… it also feels like an art and not really automated" (00:01-01:07).
- The product loop: drop in media plus context, where context can describe what happened in the files or give directions like "add captions, add music, add voiceover"; the agent then "understand[s] your media, find[s] the right moments, assemble[s] everything together, generate[s] captions, music, voiceover, b-rolls" and returns a ready-to-share clip (01:25-01:57). A second framing case is a speak-to-camera recording with pauses and unsuccessful shots, where the agent is expected to "figure it out," remove them, and return a shareable clip (02:19-02:39).
- The infrastructure comparison, slide-by-slide: both an agentic app builder and an agentic video editor have a prompt UI (media plus prompt in the video case); on the backend "there is a remote machine which is called sandbox… spinning up, and inside this machine, there is an agent with tools and skills"; the artifact is a codebase in one case and a video composition in the other; the result is an app preview versus a rendered video (02:58-04:06).
- Generating versus editing is called out as "actually the most interesting to me." Reelful does "not generate a lot of content" and expects the user's own real-life footage. The argument for why editing is harder: "if the agent has a blank canvas, it can do whatever they can. But in the editing case, the agent has to figure out which moments are the best… what to omit, what to use, how to organize everything together," while "footage can be messy or incomplete, and agent still has to deliver a very polished result, professionally made, so that ideally the viewers of this content don't get if it is like AI or human edited" (04:06-05:17).
- Pipeline order: media understanding first — what is happening in the clips and photos, plus speech transcription for speak-to-camera video (05:30-05:50). Then a creative plan is shown to the user "so that they can approve if they like it or not, what they want to change or maybe regenerate," created "before actually starting editing" (05:50-06:08). Only after approval does the sandbox spin up as the agent's execution environment (06:08-06:25).
- Skills are where the domain taste lives: "our skills are, for example, cut rules, how… to select the best moments, uh, also font pairs, which fonts are more suitable for this use case, which are not, for example, how to generate B-rolls, and this is where our taste and craft, uh, live, actually" (06:25-06:50). The agent can also initiate sub-processes: generating music that fits the exact composition, voiceover, added sounds, and animating still photos to make them more dynamic (06:50-07:12).
- Remotion: "an open-source framework to create videos as code, as React code… basically, it's just like a file with the order with all your assets and tracks and how they're following each other." The stated reason for choosing it is agent capability: "agents are really good at writing code and therefore we can use them to create videos with this remotion framework" (07:12-07:45).
- Verification layer: "of course agent can make mistakes and that's why we develop this verification layer to make sure that all the composition is clean, is well defined, everything will be rendered and if there are some problems then the agent will reiterate on the composition" (07:45-08:19).
- The delivery problem is stated as possibly larger than the pipeline: "it's a lot, right? It's like very complex workflow and ideally we don't want our users to even know anything about it. And this is even maybe a bigger problem how to deliver this complex agentic workflow to mass consumer" (08:19-08:35). Three answers follow — mobile-first, so users can edit "while driving, walking or maybe lifting weights" (08:35-08:52); directional templates, because "prompting videos can sometimes be also challenging," so a user selects a template like speak-to-camera, add b-rolls, or voiceover, drops media, and "even without any prompt it will work" (08:52-09:24); and a conventional editor, because "a lot of people are already sort of using regular video editors," where the user generates agentically first and then tweaks — "remove a second or maybe correct some word in the captions" (09:24-09:59).
- Evidence offered is a set of clips Deyneka created with the product and posted on social media, "assembled only using agent, no regular video editor" (09:59-11:08). The company is early, released a second version at the conference, and recently raised from a16z speedrun (11:08-11:50).
