## Summary

Sunil Pai presents code mode as an agent interaction pattern where models generate executable code instead of selecting many JSON tool calls. The talk uses Cloudflare API examples to show token and latency reductions, then argues that the production boundary is a capability-based sandbox with explicit APIs, network controls, fast ephemeral execution, and full observability.

## Notes

- Tool calling scales poorly when hundreds of enterprise tools or services fill context and force slow back-and-forth model turns. (01:31-02:03)
- Code mode asks the model to generate JavaScript that can use typed APIs, syntax checks, loops, state, sequencing, and parallelism to execute a multi-step workflow in one run. (02:04-03:00)
- Cloudflare's code-accepting search and execute functions reduced a roughly 1.2-1.5 million-token API surface to about 1,000 tokens of initial interface. (03:09-04:05)
- A DDoS mitigation prompt illustrates the latency argument: instead of many MCP round trips, generated code can run close to the API surface and execute the needed sequence in one shot. (04:21-05:18)
- The canvas tic-tac-toe example shows a model inspecting system state as strokes and acting inside that state machine rather than generating a separate application. (09:31-11:46)
- The proposed harness gives generated code a safe execution space where task-specific capabilities are explicitly exposed. (11:46-12:30)
- The sandbox starts with no fetches, exposed APIs, or other capabilities; external authority is granted explicitly, and outgoing network access should be controlled. (12:33-13:41)
- Full observability is required so teams can reconstruct why generated code took a significant action. (13:41-13:58)
- Future code-mode systems may generate long-running workflows with state and custom per-user UIs, increasing the importance of task-scoped capability controls. (14:16-16:40)
- Agent-facing developer experience should include Markdown docs, actionable errors, search discoverability, registries, types, and syntax errors. (17:09-17:46)
