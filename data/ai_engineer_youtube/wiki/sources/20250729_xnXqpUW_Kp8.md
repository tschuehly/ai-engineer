## Summary

Will Bryk argues that AI agents need a different search substrate than human-oriented keyword engines: neural web search can match semantic and long-context queries, LLMs still need retrieval because the web is too large and dynamic to fit in weights, and agent-facing search APIs should expose controllable parameters for high-recall, multi-step retrieval.

## Notes

- Traditional search is described as keyword indexing and comparison, while neural search embeds documents and queries so the retrieval target can include meaning and ideas rather than only exact words (03:23-05:02).
- The "shirts without stripes" example illustrates how keyword matching can overemphasize a forbidden term, while semantic search can represent negation and return non-striped results (01:48-02:00, 04:45-05:18).
- The source argues that LLMs will continue to need search because model weights cannot store the full, constantly changing web, especially once images and video are considered (06:04-07:10).
- Agent-oriented search differs from human search: agents can issue many searches, pass multi-paragraph context, process large result sets, and value exact task fit over click-optimized pages (07:33-13:51).
- Exa's API surface exposes retrieval controls such as result count, date ranges, domain filters, and neural versus keyword search mode, which are useful knobs for agentic retrieval loops (14:32-15:10).
