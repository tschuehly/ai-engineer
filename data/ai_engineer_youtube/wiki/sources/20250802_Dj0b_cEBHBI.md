## Summary

Danielle Perszyk frames useful general intelligence as human-agent co-evolution rather than isolated model intelligence. The talk argues that browser-based computer-use agents are needed because many useful digital workflows only expose visual UIs, and that reliability should begin with granular UI action primitives, structured extraction, composable Python workflows, and evaluation of human-agent interaction outcomes.

## Notes

- Current agents still struggle with reliable clicking, typing, and scrolling, so the talk treats computer-use reliability as a prerequisite for useful general-purpose agents. (03:17-03:27)
- Nova Act is described as a specialized Amazon Nova model plus SDK that turns an `act` call from natural language into actions on the screen. (08:00-08:31)
- The apartment demo combines UI navigation, structured extraction into a Pydantic schema, Python helper functions, Google Maps lookup, thread-pool parallel browser runs, and pandas tabulation. (08:41-10:01)
- The talk argues that computer-use building blocks are deceptively hard because visual icons and UI semantics vary too much to enumerate manually, so agents need exploration and reinforcement learning over real interfaces. (10:11-11:01)
- Nova Act's design focus is the smallest units of interaction plus granular developer control, so complex workflows are built by composing atomic actions. (11:48-12:05)
- The talk argues that general intelligence is social and distributed, so teams should measure interactions with agents, including creativity, productivity, strategic thinking, and flow, not only model capabilities or time spent on platform. (15:02-15:29)
