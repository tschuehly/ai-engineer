## Summary

Barry Zhang and Mahesh Murag argue that agent scaffolding is converging around general model/runtime loops, so the scarce layer is reusable domain expertise packaged as skills. Skills are simple folders with progressive-disclosure metadata, instructions, files, scripts, and optional dependencies; they can combine with MCP servers for external connectivity, be evaluated and versioned like software, and act as a transferable procedural memory that agents and humans improve over time.

## Notes

- The speakers describe code plus a runtime environment as a universal digital interface: a general agent can call APIs, organize files, analyze with Python, and synthesize outputs through code, but still lacks the domain expertise needed for consistent professional work. 01:38-02:56
- Skills are intentionally simple folders that humans or agents can create, version in Git, share through ordinary storage, and populate with scripts as tools; scripts let repeated operations live in the filesystem until needed instead of always occupying model context. 03:00-04:18
- Progressive disclosure lets a runtime show only skill metadata first, then load `SKILL.md`, core instructions, directories, and deeper assets when the task needs them, enabling libraries of hundreds or thousands of skills. 04:21-04:56, 09:46-10:05
- The talk distinguishes skill categories: foundational document or research skills, partner skills such as Browserbase Stagehand and Notion workspace research, and enterprise skills for organizational best practices, bespoke internal software, and code-style guidance. 05:00-07:25
- Skills and MCP are complementary: MCP provides external data and connectivity, while skills provide expertise and can orchestrate workflows across multiple MCP tools. 08:08-08:33, 09:34-10:31
- As skills become more complex, the speakers call for software-like practices: tests and evals for trigger timing and output quality, versioning and behavior lineage, and explicit dependencies on other skills, MCP servers, packages, or runtime environment capabilities. 10:38-11:57
- Skills are positioned as a collective and evolving knowledge base of procedural capabilities curated by people and agents; they make organizational feedback transferable because what an agent writes down in the standardized format can help future versions of itself. 12:02-13:44
