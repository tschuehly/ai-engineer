## Summary

Michael Albada frames agent design as a production engineering discipline: raise agency only when it preserves efficacy, curate tool surfaces instead of mirroring API catalogs, keep deterministic business logic outside the model, and use eval plus observability loops to move beyond anecdotal tuning.

## Notes

- Agentic development has become easier to prototype, but getting from roughly 70-80% accuracy to robust long-tail performance is much harder, 02:19-02:36 and 09:47-10:17.
- Agency should be treated as a tool for solving problems rather than a goal in itself; the system should stay high-efficacy as autonomy increases, 02:38-04:21.
- Tool calling works as an observe-act loop: parse model output, invoke a validated tool, return the observation, and repeat until a final customer-facing output is ready, 04:44-05:50.
- Do not register a large API portfolio directly as a large tool catalog; too many semantically overlapping tools reduce accuracy in individual completion calls, 05:52-06:24.
- Start with simple chains or branching workflows when they are sufficient because they are cheaper, easier to measure, and more reliable; move to freer agentic patterns when chains or trees become too complex to maintain, 06:36-08:02.
- Multi-agent decomposition is useful when tool groups can be separated by semantic domain and routed by a coordinator, but cross-team agent-to-agent discovery remains early and has unresolved technical and security questions, 08:44-09:45.
- High-quality eval sets are needed to answer basic system-design questions such as how many agents to use, how many tools to expose, which model to choose, and what memory strategy to adopt, 09:47-10:17.
- Production observability should capture detailed logs and traces, then cluster and summarize failures so teams can optimize recurring failure modes instead of isolated anecdotes, 12:56-13:36.
- Agentic systems create new vulnerability surfaces, so production stacks should include layered safety detectors, trip wires, fallbacks, and human review for critical cases, 14:42-15:12.
