## Summary

This workshop explains an ElevenLabs conversational voice-agent stack that keeps speech-to-text, LLM reasoning, text-to-speech, language detection, function calling, RAG, and voice safety controls explicit. Its durable contribution is a practical voice-agent integration view: cascaded audio pipelines trade some naturalness for monitoring and control, multilingual agents need explicit language switching, long-running tools need conversational wait handling, and generated voices need moderation, consent, and provenance controls.

## Notes

- The core pipeline is speech-to-text, text LLM reasoning, and text-to-speech; ElevenLabs uses external LLM providers such as GPT-4o and Gemini for the text reasoning layer rather than building the intelligence model itself. 08:29-09:24
- The talk contrasts cascaded pipelines with sound-token-to-sound-token realtime models: direct audio models have benefits, but the speaker says cascaded text paths give better monitoring and understanding of what happens in the conversation. 09:52-10:41
- To control latency, the platform colocates the speech, LLM, and voice models close to one another. 10:41-10:49
- Agent configuration includes LLM selection, custom OpenAI-compatible endpoints, uploaded documents or website knowledge bases, RAG, standard function calling, and system tools such as language detection. 20:37-23:33
- Multilingual support is framed as both product access and regulatory/localization fit; the Singapore demo uses English, Mandarin Chinese, Malay, and Tamil as official-language requirements. 20:37-25:05
- Agent-to-agent transfer can route a conversation silently to a different task-specific agent, potentially owned by another team and powered by a different LLM, while keeping the same voice. 37:42-38:57
- For slow enterprise calls, tool configuration can keep the agent conversational while waiting, but very long work may need an external queue and later websocket-based context injection. 39:07-43:39
- Voice safety controls discussed include live moderation, forbidden phrases for published voices, generated-speech watermarking traceable to accounts, and random-sentence readout for professional voice-clone consent. 49:06-51:34
