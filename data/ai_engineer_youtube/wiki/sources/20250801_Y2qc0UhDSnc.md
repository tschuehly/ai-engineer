## Summary

Kyle Kranen frames production inference as a Pareto-frontier problem across quality, latency, and cost, then shows how NVIDIA Dynamo-style distributed inference can move that frontier with prefill/decode disaggregation, KV-aware routing, inference-time scaling, KV manipulation around structured agent waits, worker specialization, and dynamic load balancing.

## Notes

- Application fit depends on quality, latency, and cost together: robotics may need latency for safety, tab completion needs snappiness, and async coding agents may tolerate higher latency while caring more about quality and cost (01:31-04:32).
- Pareto-frontier techniques can compound; for example, RAG may increase quality while worsening latency and cost, while quantization can then recover some latency and cost (04:35-06:01).
- Kranen groups frontier-shifting techniques under scale, structure, and dynamism: disaggregation and routing for scale, inference-time scaling and KV manipulation for structure, and worker specialization plus load balancing for dynamism (06:04-06:20, 13:11-19:58).
- Prefill/decode disaggregation separates compute-bound prefill from often memory-bound decode, enabling different worker counts and simpler scheduling than mixing prefill and decode requests on the same GPUs (06:23-08:40).
- KV-aware routing should not maximize cache match alone; it should account for both available prefix match and existing node load so the system does not route into queue buildup (11:03-13:01).
- Agent structure can become inference structure: predictable tool-call waits let the runtime offload KV state during the wait and restore it before the next LLM call instead of redoing prefill work (16:14-17:40).
