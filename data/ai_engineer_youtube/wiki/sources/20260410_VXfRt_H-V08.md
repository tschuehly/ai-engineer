## Summary

Amplifon and Quantyca describe an enterprise AI platform that combines an AI gateway, MCP registry, A2A agent registry, and use-case registry so distributed teams can discover approved tools and agents, trace which assets support each use case, and deploy standardized MCP or A2A services through templates and CI/CD.

## Notes

- The enterprise problem is distributed teams independently wiring connections, security models, and infrastructure, creating maintenance, governance, compliance, and scaling issues. (00:03-05:24)
- The AI gateway provides a unified model endpoint, Entra ID authentication, budget controls, and centralized auditing, monitoring, and analytics. (05:35-07:41)
- The platform separates three registries: an MCP registry for approved tools and integrations, an A2A registry for discoverable agents, and a use-case registry that links tools, agents, models, and business deployments. (07:41-08:52)
- MCP registry entries extend the community registry with internal servers, approved public servers, ownership, environment, authentication model, cost attribution, and use-case linkage. (08:57-11:43)
- A2A agent registry entries are based on agent cards describing identity, endpoint, capabilities, supported modalities, and authentication requirements; deployments publish agent cards into the registry through CI/CD. (11:43-12:36)
- The use-case registry captures status, version, description, ownership, linked agents and MCP servers, model usage, and lifecycle history so outages or model disruptions can be traced back to affected use cases. (12:51-17:47)
- Template repositories for MCP and A2A servers include Docker files, package management, FastAPI exposure, authentication, cost tracking, Langfuse observability, evaluation support, and framework-agnostic A2A interfaces. (17:49-19:56)
- Deployment tags trigger GitHub Actions that publish Docker images and metadata, including A2A agent cards and MCP `server.json`, into the registry backend. (20:01-20:50)
