## Summary

Craig Wattrus frames AI product UX as designing form factors for AI coworkers: invisible background work, ambient opportunity surfacing, inline artifact manipulation, and conversational build flows. The source emphasizes runnable model probes over static mockups, visible agent presence and rollback when agents act in a work surface, and bounded play as a way to discover emergent agent behaviors such as file-combining or human-escalation suggestions.

## Notes

- Flatfile's AI stack is described as real-time context from data and validation outcomes, agents with tools and jobs, and user-facing surfaces grouped as invisible, ambient, inline, and conversational. (01:29-02:14)
- Invisible AI can generate a personalized demo in the background after signup; ambient AI can mark columns with likely data-fix opportunities; inline AI can generate and run code directly over data; conversational AI can build no-code or low-code apps. (02:16-03:52)
- The talk argues that AI designers should build runnable tools to explore model behavior, moving from copy-level control toward coaching the agent's character and environment. (04:00-06:10)
- A cursor-like canvas experiment felt too constrained because the model could only move one thing at a time, while a later workspace gave the agent presence and let it read multiple files while writing another. (06:33-08:17)
- A better data-transformation UX used visual communication, intermediate checks, snapshots, rollback, and handoff when the agent could not proceed safely. (09:11-10:45)
- Exploratory prototypes revealed emergent behaviors: combining a JSON and CSV file, writing a report, recommending next actions, and escalating missing employee IDs to HR rather than pretending the agent could fix them. (11:09-14:12)
