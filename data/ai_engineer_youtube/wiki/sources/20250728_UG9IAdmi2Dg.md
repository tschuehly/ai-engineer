## Summary

Tom Moor describes Linear's path from hidden AI assistance features to a platform where agents become first-class teammates inside the same product-development system humans already use. The talk covers retrieval and product-intelligence foundations, multimodal issue creation, agent identity and auditability, event hooks and scopes, and UX norms for agents that work inside shared team communication surfaces.

## Notes

- Linear initially focused on summarization, similarity, embeddings, and hidden AI assists rather than a visible copilot, because the copilot quality bar was not met at the time (01:38-04:07).
- Search became a prerequisite for later AI features: Linear moved from simple cosine similarity over PGVector to a hybrid search stack with Turbopuffer, Cohere embeddings, query rewriting, reranking, and deterministic rules (05:13-06:40).
- Product intelligence maps relationships from an issue to related issues and explains why they are related, then powers suggested labels, assignees, duplicates, and project matches (06:40-07:22).
- Customer-feedback analysis can synthesize hundreds or thousands of requests into possible project splits and feature ideas (07:26-08:19).
- Multimodal issue creation turns customer videos into reproduction steps and issue drafts, making bug-report capture part of the product workflow rather than a separate manual translation step (09:09-09:33).
- Linear's agent platform lets agents be assigned or mentioned like users, produce plans or PRs, receive Slack-originated instructions tied to Linear issues, and expose interruption or status controls (10:29-13:25).
- Agent platform architecture includes first-class agent identity, action history, audit trails, OAuth installation, admin-managed access, a mature GraphQL API, granular scopes, and agent-specific webhooks (14:39-15:40).
- The recommended agent UX is to respond quickly, confirm the specific understood task, inhabit the platform's normal language, update issue state like a human teammate, follow thread replies without repeated mentions, clarify intent before acting, and keep output concise and useful (16:16-19:24).
