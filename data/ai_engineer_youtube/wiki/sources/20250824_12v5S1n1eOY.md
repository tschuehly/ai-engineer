## Summary

Ben Kus explains how Box evolved enterprise content AI from single-shot LLM extraction over OCR text into an agentic platform for complex document extraction, private-content Q&A, and deep research. The talk emphasizes decomposing long, field-heavy document tasks into intelligent workflow graphs with grouped fields, multimodal checks, multiple models, judge feedback, eval sets, APIs, and model-portable prompts instead of relying on a single prompt or fine-tuned model.

## Notes

- Box's enterprise context is unstructured content at scale; customers care about safe AI over sensitive files, and AI features include document Q&A, data extraction, and AI-powered workflows (00:32-02:19).
- Data extraction means turning documents, contracts, proposals, and other unstructured files into structured fields that can drive queries, workflows, search, and filtering (02:20-03:57).
- Earlier intelligent document processing required specialized models, specific content types, large training corpora, and custom vendor/model work, which limited broad automation of enterprise unstructured data (03:57-04:56).
- Single-shot LLM extraction after OCR worked well for simple cases and outperformed older specialized approaches, but customer expectations quickly escalated to long leases, many fields, complex assets, risk assessments, OCR noise, languages, and accuracy demands (05:08-08:44).
- Box's agentic extraction graph prepares fields, groups related fields, queries documents multiple times, checks results with tools, verifies OCR against page images, uses multiple vendor models, and applies judge feedback so the workflow can retry before presenting the answer (10:48-12:23).
- The same agentic foundation also supports Box deep research over private content: search, relevance checking, outline, planning, and synthesis can be represented as a directed graph over enterprise files (13:00-14:03).
- Kus argues for building the agentic architecture early when a set of AI models could plausibly solve a hard workflow, while keeping the agentic framework distinct from the distributed system that scales over large document volumes (14:14-16:24).
- Box exposes the agent platform through APIs and tools, and uses standard evals, harder challenge evals, LLM-as-judge, and user feedback to evaluate agent behavior (16:45-17:54).
- Box currently favors prompts, cached prompts, and agentic workflow structure over fine-tuning because it supports multiple model providers and future model versions (18:18-18:54).
