# Autonomous Coding Agents Are Still Early In PR Production Data

Summary: Broad AI coding adoption does not imply broad autonomous-agent adoption. Production PR data can show interactive tools becoming normal while fully autonomous coding agents remain mostly experimental and a small share of merged work.

Use when:
- Separating interactive coding-assistant rollout from autonomous-agent rollout.
- Calibrating claims that autonomous coding agents are already the default delivery path.

Details:
- Jellyfish's adoption and productivity signals are described as overwhelmingly coming from interactive coding tools such as Copilot, Cursor, and Claude Code. (04:32-04:48)
- In the data set, only about 44% of companies had any autonomous-agent activity in the prior three months. (05:09-05:16)
- Most autonomous-agent activity was characterized as trying and experimentation rather than full-scale production, and it accounted for less than 2% of merged PRs in that period. (05:16-05:34)
- The talk's practical calibration is that teams can see productivity gains from interactive coding tools before autonomous agents are mature at scale. (05:38-05:51)
