# Ground Generated Media With Current Search Context

Summary: Image-generation workflows can combine generative media models with current retrieval so outputs reflect up-to-date facts, public context, and precise text rather than only the model's training cutoff.

Use when:
- Generating images, infographics, stickers, comics, or localized visuals that depend on current facts or public context.
- A media model needs text rendering, translation, or personalized references that should be grounded before image synthesis.

Details:
- Nano Banana Pro is described as powered by Google Search for world knowledge, enabling prompts such as generating a detailed infographic after searching for relevant information. 02:49-03:06
- The model's media-specific improvements include text rendering, multilingual localization, consistency across many people, creative controls such as changing focus while preserving the rest of an image, and multiple aspect ratios. 03:07-04:16
- In the laptop-sticker demo, AI Studio uses Google Search grounding to gather current context about a person before generating personalized stickers. 10:48-11:20
- The presenters note the same pattern for current news events: retrieval can supply relevant same-day information instead of relying on the model knowledge cutoff. 11:43-11:55
