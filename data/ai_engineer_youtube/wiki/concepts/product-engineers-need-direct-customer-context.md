# Product Engineers Need Direct Customer Context

Summary: Product engineers need direct exposure to customer pain, requests, and product outcomes. In an AI-assisted environment, implementation skill matters less unless paired with judgment about what customers actually need.

Use when:
- Setting expectations for engineers whose work shifts from coding tasks toward product ownership.
- Designing context systems that make customer feedback visible to engineering teams.

Details:
- Artman predicts engineers will need to become more product-oriented because AI can increasingly handle data-piping implementation while humans still need to know what customers want and what good UX looks like. (26:41-27:34)
- Linear exposes engineers to customer Slack channels, recorded customer meetings, and tagged feedback so they can search for what customers are saying about functionality. (25:03-25:47)
- The source recommends building for yourself, shipping to real users, and using the resulting feedback to learn whether you are building the right thing; Apple Human Interface Guidelines are suggested as useful UX reading. (28:15-28:53)
