# Agentic Coding Transforms Existing Software

Summary: The durable value of coding agents is not only making greenfield demos faster. A larger opportunity is transforming existing applications through migrations, dependency upgrades, language transitions, and deeper product changes that are hard, risky, or unpleasant for humans.

Use when:
- Prioritizing coding-agent investments beyond prototype generation.
- Evaluating whether a mature codebase has maintenance or migration work suitable for agents.

Details:
- Brockman predicts that agentic coding will overtake purely interactive vibe-coding loops as agents become more like cloud coworkers that can run while the user's laptop is closed. 24:10-24:48
- He distinguishes flashy scratch-built app demos from deeper transformation of existing applications. 24:57-25:15
- Legacy codebases, migrations, library updates, and language transitions are called out as hard and not very fun for humans, but increasingly tractable for AI systems. 25:15-25:34
- The productivity target is company-level speed, not only faster typing or small app generation. 25:35-25:52
