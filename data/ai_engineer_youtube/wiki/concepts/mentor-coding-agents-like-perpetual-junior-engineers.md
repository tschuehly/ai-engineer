# Mentor Coding Agents Like Perpetual Junior Engineers

Summary: Coding agents should be treated as perpetually junior engineers: fast, parallel, and capable when given the right context, but weak at retaining organizational knowledge across sessions. The human role shifts toward tech-lead-style mentoring through outcomes, constraints, context, and evaluation.

Use when:
- Framing how engineers should delegate work to coding agents.
- Explaining why agent adoption needs structured guidance rather than ticket assignment alone.

Details:
- Productive agent use is not just assigning tickets; engineers should mentor agents by supplying outcomes, context, constraints, and boundaries the way a tech lead scaffolds work for a junior engineer. 05:22-05:49, 09:03-10:27
- AI and new engineers both start without local system and organizational context, but AI differs by processing supplied information quickly while forgetting across conversations. 09:27-10:18
- This makes the engineer a perpetual tech lead for AI apprentices: the agent can execute multiple tasks quickly, while the human supplies structure, guidance, and review. 10:10-10:27
- In the live example, the agent was given behavioral boundaries rather than exact implementation steps, then ran in the background while the human returned later to evaluate the result. 04:17-04:48
