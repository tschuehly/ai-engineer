# Demo Culture Replaces Memo-First Product Persuasion

Summary: When agentic prototyping makes code cheap, product teams can use demos as the first persuasion artifact instead of memos, decks, or long pre-approval processes. A felt prototype can reveal weird or risky ideas that would be hard to judge from text alone.

Use when:
- Choosing whether to write a product memo or build a fast agentic prototype.
- Explaining how cheap code changes product discovery and stakeholder review.

Details:
- The source says Every is moving from memo or deck persuasion toward demo culture because an agentic prototype can be built in a couple of hours. (07:20-07:54)
- Demos let stakeholders feel an idea directly, which enables stranger product concepts that might not survive abstract document review. (07:53-08:11)
- Cheap code also lowers the starting energy for risky experiments and refactor research, allowing more attempts than a traditional implementation workflow would justify. (06:51-07:14)
