# Measure AI Intensity by Human Input to Valuable Output

Summary: AI-intensive products can be compared by the ratio of human input to valuable AI output. This framing is more actionable than arguing whether a system is a workflow or an agent.

Use when:
- Classifying AI products by autonomy or intensity without relying on vague agent labels.
- Designing a product surface that should produce more useful output from less user prompting.

Details:
- The talk argues that "workflow versus agent" is less important than whether the system delivers value per unit of human input. (09:25-09:44)
- Examples form a spectrum: autocomplete reacts to small typing events, chat systems produce roughly one response per user query, reasoning systems spend more model work per prompt, deep research/notebook products produce larger artifacts, and ambient agents aim for useful output with no immediate prompt. (09:44-10:35)
- The same lens also prevents blanket rebranding: voice agents, computer-use systems, and workflow agents can be judged by the value and control shape they provide instead of whether every track is called an agent. (09:12-09:31)
- Product teams should use the ratio to ask whether added intelligence is useful and non-annoying, not simply whether the system seems more agentic. (12:08-12:23)
