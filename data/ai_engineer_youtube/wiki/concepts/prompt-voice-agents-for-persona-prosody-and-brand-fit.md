# Prompt Voice Agents for Persona, Prosody, and Brand Fit

Summary: Voice-agent prompting controls not only task behavior but also spoken delivery. Demeanor, tone, enthusiasm, pacing, and brand realism become part of the product contract because users experience them directly through audio.

Use when:
- Designing prompts for a voice-first user experience.
- Evaluating whether a voice agent sounds appropriate for a brand or workflow.

Details:
- Unlike text agents, voice agents can be prompted for spoken attributes such as demeanor, tone, enthusiasm, and how the model should sound, 09:55-10:32.
- Prompt structure can include role, greeting, description, and user-facing instructions so complex realtime voice tasks have both behavioral and delivery guidance, 11:23-11:35.
- The talk cites brand realism and customization as important for voice experiences, with Tinder's Rizz Chat used as an example where voice style affected perceived user experience, 16:14-16:26.
