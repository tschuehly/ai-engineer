# Skills Turn Procedural Feedback Into Transferable Agent Memory

Summary: Skills can act as a limited but practical memory layer: they preserve reusable procedural knowledge from feedback so future agents and teammates can perform the task with less rediscovery.

Use when:
- Converting repeated agent failures or human corrections into durable workflow knowledge.
- Distinguishing procedural memory from general conversation history or broad factual memory.

Details:
- The speakers describe skills as a collective, evolving knowledge base of capabilities curated by people and agents inside an organization, where feedback and institutional knowledge improve all agents using the shared skill set. 12:02-12:56
- The standardized skill format makes learning transferable: anything the agent writes down as a skill can be used efficiently by a future version of itself. 13:20-13:44
- Skills do not capture every kind of memory; they are best suited to procedural knowledge the agent can apply to specific tasks. 13:44-13:57
- Skills are flexible enough for daily-changing knowledge because they can be acquired, updated, or dropped through in-context loading without retraining the model. 13:57-14:29
