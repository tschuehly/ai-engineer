# Use Agency Instead of Trickery for AI Delight

Summary: AI delight should make users feel like they are steering a powerful system, not being surprised by an opaque trick. The product should connect the user's input, sources, and intent to the generated result so the magic still feels self-directed.

Use when:
- Designing AI-generated outputs that may feel surprising, playful, or unfamiliar.
- Deciding whether an AI feature should be a button, workflow, artifact transformation, or guided user action.

Details:
- The source recommends surfacing delightfulness through agency rather than trickery; users should feel part of the action and able to steer it. 18:23-18:40
- NotebookLM audio generation is used as an example: the user knew which document they uploaded and expected the system to make something from that material, so the result felt like equal parts user and machine. 18:40-19:02
- Delight lives between technical capability and user expectations; after trust is built, the product can push users one step beyond the familiar without making the system feel unsettling. 17:40-18:23
