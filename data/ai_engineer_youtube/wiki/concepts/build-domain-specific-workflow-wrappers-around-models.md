# Build domain-specific workflow wrappers around models

Summary: Durable AI application value comes from the thick product layer around models: domain knowledge, automatic context packaging, orchestration, workflow-specific UX, and safe review surfaces. A generic text box is weak differentiation unless it is only a learning prototype.

Use when:
- Designing "Cursor for X" products for a profession or vertical workflow.
- Evaluating whether an AI application is a thin prompt wrapper or a defensible workflow product.

Details:
- Guo argues code was first not only because it is structured text with deterministic validation, but because engineers understood the coding workflow deeply enough to build tools for themselves. 12:17-13:18
- Cursor is cited as a thick wrapper: multiple models do diffs, merges, and embeddings; the product packages context, prompts models skillfully, supports rules, improves retrieval freshness through use, and presents edits in a familiar reviewable UX. 13:38-14:41
- The general recipe is to avoid a generic text box, bring domain and workflow knowledge to the user by default, collect and package context from the right sources, orchestrate the right model at the right moment, and present outputs thoughtfully. 14:47-15:48
- The talk frames execution as the moat: the durable advantage is building a thick workflow product and staying ahead as model releases and cost changes keep shaking the game board. 20:53-23:16
