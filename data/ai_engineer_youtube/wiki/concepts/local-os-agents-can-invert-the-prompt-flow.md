# Local OS Agents Can Invert the Prompt Flow

Summary: A local OS-level agent can shift the interaction from "human prompts AI" to "AI prompts human for decisions and missing inputs." The agent ingests personal state, works in the background, and surfaces the next decision or task through generated or native UI.

Use when:
- Designing consumer agents that operate across notifications, email, todos, files, and installed apps.
- Evaluating whether an agent should wait for explicit prompts or proactively organize the user's next actions.

Details:
- The talk imagines a computer that ingests notifications, emails, todos, and recent activity, then greets the user with the next task based on how long they were away instead of exposing stale tabs and update prompts (17:32-18:19).
- In the inverted flow, productive users delegate most work to the AI; the AI then prompts them for decisions, forms, questionnaires, or missing artifacts such as a passport photo (18:19-18:47).
- The source predicts ordinary consumer apps fade into task-first computing where UI appears on demand for the task, while specialist software remains for domains such as color grading, film, or music production (18:47-19:27).
- Local device agents are attractive for ordinary users because they can use installed app tools without consuming cloud credits or moving personal data off device; the speaker cites local models, Siri-style tool capabilities, and Android/Pixel app control as the likely direction (19:27-19:52).
