# Merchant-Owned Generative Surfaces Travel Into Chat Interfaces

Summary: Agentic commerce does not have to erase merchant-owned surfaces; it can make brand, product, and checkout components portable into chat and agent clients. The design target is a transportable commerce surface that preserves merchant representation while meeting users inside AI workflows.

Use when:
- Designing brand-controlled AI shopping experiences or deciding how a merchant appears inside chat clients.
- Evaluating whether a website, AI subdomain, MCP server, or embedded component surface should own the commerce interaction.

Details:
- Behrens describes an agent-optimized website that can dynamically combine product catalog data and brand style guidelines, then return content directly into the user's chat interface. (03:33-03:52)
- In the Samsung example, New Generation connects product data to company data, wraps products in brand and design-system context, and creates an AI subdomain for rapid experiments with generative interfaces. (13:21-14:11)
- The generated commerce interface is not only text; the talk calls for conversations that include images, products, and content. (14:11-14:20)
- Agentic transactions invert the usual website posture by making payment flows work on a new surface for bot traffic rather than treating bots only as unwanted visitors. (14:23-14:36)
- In Q&A, Behrens says brands still want to own a surface, but that surface should be transportable so shopping data and components can be brought into chat products without rebuilding the commerce stack. (16:43-17:12)
