# Cognitive exhaust gains value through cross-source synthesis

Summary: Digital byproducts such as emails, journals, tasks, browser history, notes, and CRM entries become more useful when analyzed together. The reusable pattern is to keep sources read-only, synthesize across them in a workspace, and emit reviewable artifacts.

Use when:
- Building personal intelligence workflows that should reveal patterns rather than automate actions.
- Looking for durable value from fragmented personal or organizational data sources.

Details:
- The talk defines cognitive exhaust as digital activity that is a byproduct of thinking; single records may be low value, but combined signals can diagnose recurring patterns (00:39-00:55).
- Cross-source analysis can reveal intention-action gaps, attention drift, and relationship decay because no single tool knows the user's whole behavior (01:03-01:26).
- The demonstrated architecture separates read-only sources, an analysis workspace, and reviewable outputs such as an Obsidian vault, Notion workspace, or text files (01:29-01:51).
- A weekly reflection workflow uses a command or skill to launch a script, collect read-only source data, ask the Anthropic API for structured outputs, and produce Markdown for human review (02:11-02:46).
- A relationship workflow combines recent reading, browser data, curated databases, and CRM or friend-relationship records to suggest people to discuss a topic with, while leaving the actual outreach to the user (03:41-04:08, 04:14-07:04).
