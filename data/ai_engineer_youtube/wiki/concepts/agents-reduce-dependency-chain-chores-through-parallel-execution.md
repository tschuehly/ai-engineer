# Agents reduce dependency-chain chores through parallel execution

Summary: Agents can create leverage by taking over prerequisite chores and running them in parallel, not just by autonomously completing the headline task.

Use when:
- Deciding whether a messy setup, integration, dependency, or vendor-research task is a good agent candidate.
- Explaining why agent productivity should include blocked-work reduction and parallelism, not only lines of code or fully autonomous completion.

Details:
- Swyx identifies "dependency tree crawling" as an underappreciated agent use case: installing dependencies, fixing Python environments, wiring integrations, and clearing prerequisite work that humans often avoid or serialize. (04:16-04:35)
- He argues that productivity models miss part of the benefit when they focus only on autonomy and ignore parallelism plus the removal of prerequisite chores. (04:35-04:47)
- In the AI Engineer workflow, connecting Devin to Figma was itself delegated to another agent-like tool before Devin could turn design artifacts into a working website. (04:02-04:15)
