# Human Control Planes Turn Agent Swarms Into Manageable Organizations

Summary: A human control plane for AI labor makes many agents manageable by exposing roles, projects, tasks, memories, budgets, and handoff state as an organization rather than as scattered chat tabs.

Use when:
- Designing an interface for supervising many heterogeneous agents.
- Deciding whether agent orchestration needs org-chart, project, and task abstractions instead of one generic chat.

Details:
- Paperclip presents the human as the accountable operator and uses an org chart of agents so the operator can assign work through a CEO, executives, and individual contributors while preserving human taste and preferences.
- Agent employees can be backed by different systems such as Codex, Claude Code, Gemini, Pi, Hermes, OpenClaw, Cursor, or OpenCode, with shared Paperclip memory and communication around the organization.
- The control plane tracks projects, task assignment, live agents, monthly spend, per-agent and per-project budgets, and default concurrency so operators can debug and constrain the work instead of only reading logs.
- The talk argues that the operator still has to communicate values and quality expectations because the tools can execute many tasks but do not know what the human values.
