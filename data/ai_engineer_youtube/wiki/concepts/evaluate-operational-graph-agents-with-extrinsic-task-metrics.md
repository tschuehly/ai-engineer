# Evaluate Operational Graph Agents With Extrinsic Task Metrics

Summary: Graph quality for operational agents should be judged by whether the graph improves the real workflow, not only by intrinsic graph completeness or retrieval statistics. In change-management systems, useful metrics should map back to ticket resolution, test accuracy, execution quality, and customer value.

Use when:
- Evaluating knowledge graphs or digital twins that sit inside operational agent workflows.
- Choosing metrics for graph-backed ITSM, network operations, or incident automation systems.

Details:
- The speaker says evaluation is critical for understanding how the agent system, knowledge graph, and digital twin deliver customer value. 17:45-18:04
- For the knowledge graph, the team focuses on extrinsic metrics rather than intrinsic ones because measurements should map back to customer use cases. 18:04-18:15
- The described workflow makes those extrinsic targets concrete: summarize tickets, assess impact, choose the right tests, execute test cases, report pass/fail results, and recommend remediation. 12:37-17:32
