# Dedicated Vector Databases Remain Common RAG Infrastructure

Summary: Dedicated vector databases remain a common production context store for AI systems. Their adoption suggests many teams see enough retrieval value to use specialized infrastructure rather than only general-purpose databases with vector extensions.

Use when:
- Evaluating whether RAG infrastructure needs a dedicated vector database or can stay inside an existing database.
- Describing current production practice around context storage for AI systems.

Details:
- Amplify's survey asked where context lives and how teams retrieve it; 65% of respondents reported using a dedicated vector database. (09:35-09:44)
- The speaker interpreted this as evidence that, for many use cases, specialized vector databases provide enough value over general-purpose databases with vector extensions. (09:44-09:52)
- Among dedicated vector database users, 35% primarily self-hosted and 30% primarily used a third-party provider. (09:52-10:02)
