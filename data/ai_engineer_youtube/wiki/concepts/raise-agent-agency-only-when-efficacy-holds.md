# Raise Agent Agency Only When Efficacy Holds

Summary: Agency is not an end state; it is a design lever that should be increased only when the resulting system remains effective for the user task.

Use when:
- Deciding whether to replace a deterministic workflow, chain, or tree with a freer agent loop.
- Reviewing an agent product that feels autonomous but does not reliably complete the intended work.

Details:
- The talk defines an AI agent as an entity that can reason, act, communicate, and adapt, but warns that "agenticness" should be considered alongside system effectiveness rather than optimized by itself, 02:38-03:23.
- Robotic process automation is low-agency but high-efficacy; its weakness is brittleness under changing inputs, which agentic systems can address only if they preserve task performance, 03:23-04:17.
- Low-efficacy high-agency systems are the failure mode to avoid: adding autonomy that creates bad outcomes is worse than a simpler workflow that reliably delivers value, 04:17-04:42.
